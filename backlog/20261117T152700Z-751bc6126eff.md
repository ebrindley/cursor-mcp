# Support current terminal gateway routing

## Description

## Scope / Surfaces Affected
Support authenticated GetMachine port tokens and proxy URL templates for terminal port 26054. Change src/terminal-gateway.ts, focused gateway tests, docs/terminal.md and the required patch version.

## Acceptance Criteria
Legacy connections retain their URL. A matching port token takes precedence over the legacy network token. Proxy templates substitute tenant, normalized pod ID and port and yield TLS-only WebSockets. Credentials stay private and machine identity remains tenant/cluster/pod. MachineReference ProtoJSON remains machine.pod; workers and Windows support are out of scope.

## How to Verify
Use fake GetMachine and WebSocket transports to verify URLs, token selection, template handling, unusable routing and unchanged machine pinning under Node 24. Run changed-test selection and typecheck, then Claude Opus 5.5 medium review and repository CI before landing separately.
