# Expose run reply in structured get_run results

## Description

## Scope / Surfaces Affected
- `cursor_get_run` and `cursor_wait_run` result shaping (RUN_OUT in src/tools/agents.ts), tests, docs/reference.md.
- Out of scope: other tools' text fencing, run export.

## Acceptance Criteria
- When a run has a final reply, structuredContent includes `reply`: the same fenced, labelled untrusted envelope (src/untrusted.ts `wrap`) that the text content carries, under the same byte budget and truncation notice.
- `resultBytes` unchanged; no unfenced copy of the reply anywhere in structuredContent.
- No reply -> no `reply` field.

## How to Verify
- Focused vitest on tests/agents.test.ts: reply present/absent, fence markers present, truncation applied, no raw reply outside the fence.
- Live: Claude Code headless (`claude -p`) reads a finished run's reply via cursor_get_run.
