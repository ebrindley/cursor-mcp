# Accept local file paths for prompt images

## Description

## Scope / Surfaces Affected
- `images` input on `cursor_create_agent` and `cursor_create_run` (src/prompt-images.ts, src/tools/agents.ts), docs/reference.md, docs/cursor-capabilities.md, tests.

## Acceptance Criteria
- New shape `{path, dimension?}`; `url`, `data`, `mimeType` not allowed with it.
- File read via `readTrustedFile` under `trustedRoot()`; refused when no trusted root.
- Extension .png/.jpg/.jpeg/.gif/.webp must match the magic bytes; mimeType derived from bytes.
- 15 MB per image and 15 MB combined decoded per call; existing 5 MiB inline-data cap unchanged.
- All files validated before any network call; errors name the image index only, never the path.

## How to Verify
- Focused vitest with real fixtures per format, mismatch, outside-root symlink, size limits, mixed inputs, no network on invalid input.
- Live: attach a real screenshot from Claude Code and Codex.
