# Distinguish synchronous terminal send failure from queued submission

## Description

## Scope / Surfaces Affected
Accepted H16 accounting defect in TerminalGateway and its existing tests.

## Acceptance Criteria
A synchronous WebSocket send exception reports submitted false and does not invoke the submission callback. Successfully queued requests retain unknown delivery on disconnect or timeout, including existing immediate-response adapters. No replay or retry is added.

## How to Verify
