# Surface observed stream retention and recovery guidance on run reads

## Description

## Scope / Surfaces Affected

Add bounded retention/recovery visibility to existing run reads following the retention guidance in the recovery design. No polling service, scheduler or fabricated expiration timestamps.

## Acceptance Criteria

Report a known observed duration as an observation or estimate with source/date, and missing evidence as unknown. Never compute an expiry deadline without an established epoch. Point ERROR/CANCELLED users to the recovery playbook; do not suppress useful guidance simply because a FINISHED run has a PR. Preserve existing result contracts.

## How to Verify

Focused tests for each relevant status, missing retention evidence and honest labels. Verify documentation against dated evidence; no live probes needed.

## Context / Related Work

See `.poetic/planning/cursor-recovery-design.md` for the proposed recovery contracts. These tools are future work; they are not shipped by the initial source release.
