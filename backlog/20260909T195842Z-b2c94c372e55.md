# Add cursor_read_artifact for bounded server-side downloads

## Description

## Scope / Surfaces Affected

Add a separate artifact read/download tool; preserve cursor_get_artifact_url unchanged. Reuse export storage authorization/publication for local large files. No browser-cookie integration, raw URL contract changes or live agent mutation.

## Acceptance Criteria

Use separate download transport with no forwarded Cursor authorization and refuse redirects. Enforce size bounds before buffering. Return small text through existing sanitization and response caps; large files via an explicitly authorized, nonoverwriting local path. Preserve scope checks and cancellation. Label updatedAt freshness as a heuristic rather than run provenance. Depend on completed run-export storage contract.

## How to Verify

Fake transport/temporary storage tests for headers, redirects, declared and streamed size bounds, cancellation, small text sanitization, path publication and failures. Never use real credentials in fixtures.

## Context / Related Work

See `.poetic/planning/cursor-recovery-design.md` for the proposed recovery contracts. These tools are future work; they are not shipped by the initial source release.
