# Add cursor_export_agent for an agent-level evidence bundle

## Description

## Scope / Surfaces Affected

Build on cursor_export_run and explicit-ID batch inspection. Add an agent-level bundle of agent JSON, run list, usage and per-run exports; optional artifacts and legacy conversation when available. Keep output counts/statuses/paths bounded. No launches, new transport, or automatic mutation of cloud agents.

## Acceptance Criteria

Use explicit agent IDs, scope checks and serial bounded export pacing. Prefer ERROR/CANCELLED runs; preserve complete outputs. Preserve and report incomplete raw/sidecar members, continue other members, and require explicit operator handling before retrying a colliding member; never overwrite or append. Expose compact resumable state and distinguish missing, failed, partial and complete members. Record available target branch metadata without assuming it proves a push. Depend on completed run export; follow `.poetic/planning/cursor-recovery-design.md`.

## How to Verify

Fake-client and temp-directory tests for complete/incomplete member resume, scope denials, collisions, cancellation, rate limiting and bounded outputs. No live campaign interaction.

## Context / Related Work

See `.poetic/planning/cursor-recovery-design.md` for the proposed recovery contracts. These tools are future work; they are not shipped by the initial source release.
