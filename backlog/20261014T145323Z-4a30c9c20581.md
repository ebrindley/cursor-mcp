# Accept customSubagents on agent create

## Description

## Scope / Surfaces Affected
- `cursor_create_agent` input/output and request body (src/tools/agents.ts), Agent response schema (src/schemas.ts), tests, docs/reference.md.

## Acceptance Criteria
- Optional `customSubagents` (<=20) per OpenAPI CustomSubagent schema, forwarded on create only; names unique and not colliding with built-ins (explore, shell, debug, computerUse, cursorGuide).
- Readback compares returned Agent.customSubagents names with requested; reports verified/unverified.
- No change to cursor_create_run (create-only in the published contract).

## How to Verify
- Focused vitest: schema limits, duplicate/built-in rejection before I/O, forwarding, readback.
- Live: create with one custom subagent and prompt the agent to delegate to it; confirm via stream tool calls or result.
