## Scope / Surfaces Affected
- `src/tools/terminal.ts`: the byte-size schema refines on `execute.command` and `session_input.data`; `min(1)` and the NUL check stay.
- `src/terminal.ts` and `src/terminal-sessions.ts`: the `invalid_request` returns for oversized payloads gain `reason`, `bytes`, and `maxBytes`.
- Tests in `tests/terminal.test.ts` and `tests/terminal-sessions.test.ts`; one paragraph in `docs/terminal.md`.

## Acceptance Criteria
- An oversized `command` or `data` returns `invalid_request` with `commandOutcome` or `inputOutcome` of `not_submitted`, a `reason`, and the byte counts.
- Every other refusal is unchanged; a rejected attempt creates no command record and consumes no input sequence.
- Tests cover the boundary, a multibyte oversized payload, and identifier reuse after a rejection.

## How to Verify
- `npx vitest run tests/terminal.test.ts tests/terminal-sessions.test.ts`.
- `npm run typecheck && npm test`.
